# Модели

| модель | размер | для чего |
|---|---|---|
| Base | 57 МБ | очень быстро, средняя точность |
| Small | 181 МБ | лучший выбор без видеокарты |
| Medium | 514 МБ | точнее, но на процессоре медленно |
| **Large v3 Turbo** | 547 МБ | точно и быстро на видеокарте |
| Large v3 Turbo Q8 | 834 МБ | чуть точнее, больше памяти |
| Large v3 | 1080 МБ | максимум точности, медленно |

Модель скачивается в **Настройки → Распознавание**. Загружается только та модель, которой вы
пользуетесь, и выгружается, если ей долго не пользоваться.

## Источники

Модели Whisper берутся с [huggingface.co/ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp),
Silero VAD (0,9 МБ) — с [huggingface.co/ggml-org/whisper-vad](https://huggingface.co/ggml-org/whisper-vad),
обе под лицензией MIT. Если Hugging Face недоступен, переключите **Источник** на зеркало
[hf-mirror.com](https://hf-mirror.com).

В любом случае файл сохраняется, только если его размер и SHA-256 совпали с опубликованными;
несовпавший файл удаляется.

## Свой сервер

Выберите источник **Свой сервер…** и введите адрес сервера с такой же структурой, как у
huggingface.co (`<адрес>/ggerganov/whisper.cpp/resolve/main/ggml-<имя>.bin`, а для модели VAD —
`<адрес>/ggml-org/whisper-vad/resolve/main/ggml-silero-v5.1.2.bin`). Адрес должен начинаться с
`https://` (`http://` — только для localhost). Официальные модели по-прежнему сверяются с
опубликованной SHA-256; отметьте **Не сверять опубликованную SHA-256** только если на вашем
сервере лежат файлы, отличающиеся от официальных.

## Журнал загрузки

Пока модель скачивается, в настройках виден журнал: источник, точный URL, куда сервер
перенаправил (Hugging Face отдаёт файлы со своего CDN), результат проверки суммы и куда файл
сохранён. Те же строки дописываются в `~/.local/share/sotto/download.log` и в журнал
(`journalctl --user -t sotto`). Пока идёт загрузка, источник и параметры проверки заблокированы.

## Свои файлы

Положите любую `ggml-*.bin` в `~/.local/share/sotto/models/` и выберите её в настройках.

## Язык

**Определять автоматически** подходит почти всегда. Если вы всегда говорите на одном языке,
выберите его: распознавание станет чуть быстрее, а короткие фразы не будут путаться.
