# Если не работает

## Журнал

```sh
journalctl --user -t sotto -f     # рабочий стол, чем нажимаются клавиши, фразы, движок, скорость
SOTTO_DEBUG=1 sotto               # подробности whisper.cpp, ggml и sherpa-onnx
```

Каждая диктовка пишет в журнал свои фразы (`phrase of 3.2 s`), сколько заняла каждая
(`sherpa-onnx: 3.2 s in 310 ms`) и как вставлен текст (`paste via wtype ok`).

## Частые проблемы

| проблема | что сделать |
|---|---|
| Долго распознаёт | с Whisper в журнале `gpu: off`: поставьте драйвер Vulkan (в Arch ещё `ggml-vulkan`) или возьмите GigaAM или Parakeet — они быстры на процессоре |
| Фразы печатаются слишком рано, предложения рвутся | увеличьте **Пауза в конце фразы** (800–1000 мс) |
| Фразы печатаются слишком поздно | уменьшите её (400 мс) |
| Ноутбук считает не на той видеокарте | Sotto берёт дискретную; другую можно выбрать в **Настройки → Ускорение**. В журнале перечислены все видеокарты, которые он видит (`gpu 0 …`) |
| Видеокарты NVIDIA нет в списке | её не видит Vulkan, и настройки говорят почему: драйвер не загружен или карта выключена (выберите гибридный режим в envycontrol, supergfxctl или optimus-manager), драйвер обновился и нужна перезагрузка, или не установлена его часть для Vulkan (`nvidia-utils` в Arch, `nvidia-vulkan-icd` в Debian). Карта должна быть в выводе `vulkaninfo --summary` |
| Текст не вставляется в KDE, GNOME или COSMIC | **Настройки → Доступ к вводу → Разрешить…**; в терминалах выберите Ctrl+Shift+V |
| Текст не вставляется в Hyprland, niri или sway | поставьте `wtype`; когда он найден, в журнале будет `ways to press keys: ("wtype")` |
| «Нечем нажать клавиши» | нет ни портала, ни wtype, ни ydotool, ни xdotool: поставьте `wtype` (Wayland) или `xdotool` (X11) |
| ydotool ничего не делает | ему нужны запущенная служба `ydotoold` и доступ к `/dev/uinput` |
| Клавиша не срабатывает | проверьте её через **Изменить…**; в тайлинговых композиторах добавьте бинд из настроек или из `sotto --keybind` |
| Нет значка в трее | в композиторе нет трея (добавьте его в панель); настройки открываются командой `sotto --settings` |
| Имена пишутся неправильно | добавьте их в **Словарь** (Whisper) |
| GigaAM пишет английские слова кириллицей | она знает только русский; для смешанной речи возьмите Parakeet |
| Модель не скачивается | переключите **Источник** на зеркало; файл с неверной суммой удаляется, попробуйте ещё раз |
| В списке нет GigaAM и Parakeet | эта сборка без sherpa-onnx (`--no-sherpa` или сборка из исходников без него): запустите `./install.sh` ещё раз |
| Индикатор — обычное окно | не хватает `layer-shell-qt` (при установке из исходников) |
| GNOME: индикатор забирает фокус, текст никуда не вставляется | на GNOME Sotto работает через XWayland, чтобы такого не было; для этого нужны X11-плагин Qt (`qt6-qpa-plugins` в Debian и Ubuntu) и XWayland. `QT_QPA_PLATFORM=wayland sotto` отключает это |
| COSMIC: текста нет в буфере обмена | запускайте сеанс с `COSMIC_DATA_CONTROL_ENABLED=1`, чтобы `wl-copy` мог его туда положить |
| У AppImage нет клавиши | запустите его один раз обычным способом, чтобы он добавил себя в меню |
| Пустые значки | не хватает SVG-плагина Qt: `qt6-svg` (Arch), `qt6-svg-plugins` (Debian, Ubuntu), `qt6-qtsvg` (Fedora) |
