# Если не работает

## Журнал

```sh
journalctl --user -t sotto -f     # микрофон, длина записи, видеокарта или нет, скорость
SOTTO_DEBUG=1 sotto               # подробности whisper и ggml
```

## Частые проблемы

| проблема | что сделать |
|---|---|
| Долго распознаёт | в журнале `gpu: false`: поставьте драйвер Vulkan (в Arch ещё `ggml-vulkan`) или выберите **Small** |
| Текст не вставляется | **Настройки → Доступ к вводу → Разрешить…**; в терминалах выберите Ctrl+Shift+V |
| Клавиша не срабатывает | проверьте её через **Изменить…** или повесьте любую клавишу на `sotto --toggle` |
| Имена пишутся неправильно | добавьте их в **Словарь** |
| Модель не скачивается | переключите **Источник** на зеркало; файл с неверной суммой удаляется, попробуйте ещё раз |
| Индикатор — обычное окно | не хватает `layer-shell-qt` (при установке из исходников) |
| У AppImage нет клавиши | запустите его один раз обычным способом, чтобы он добавил себя в меню |
