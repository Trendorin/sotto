# Sotto

Лёгкий голосовой ввод для Linux. Нажали клавишу, сказали, отпустили, и текст появился там, где стоит курсор.

- **Нативный и лёгкий.** C++ / Qt 6 / whisper.cpp, без Python и Electron. В простое занимает несколько мегабайт, модель выгружается из памяти, если ей долго не пользоваться.
- **Выглядит как система.** Обычные виджеты Qt: тема, акцентный цвет и шрифты берутся из системы (Breeze, Adwaita и т. д.).
- **Нормально работает на Wayland.** Индикатор сделан через `wlr-layer-shell`: висит поверх окон и не забирает фокус. Горячая клавиша идёт через портал `GlobalShortcuts`, вставка текста через портал `RemoteDesktop`. Root и `ydotool` не нужны.
- **Быстро.** Ускорение на видеокарте через Vulkan (`ggml-vulkan`). Модель начинает грузиться, пока вы говорите. Silero VAD отсекает тишину, поэтому whisper не выдумывает фразы и не тратит время на паузы.

## Установка

### Arch / CachyOS / Manjaro

```sh
./install.sh
```

Скрипт собирает настоящий пакет pacman. Зависимости, включая `ggml-vulkan` для видеокарты, ставятся сами, а запущенная копия перезапускается на новой версии.

### AppImage (любой дистрибутив)

```sh
chmod +x Sotto-*-x86_64.AppImage && ./Sotto-*-x86_64.AppImage
```

Один файл, внутри всё нужное: Qt, whisper.cpp, Vulkan-ускорение и CPU-сборки под любой процессор. Работает на дистрибутивах с glibc 2.35 и новее (Ubuntu 22.04+, Debian 12+, Fedora 36+, Arch). При запуске AppImage добавляет себя в меню приложений: кладёт `~/.local/share/applications/io.github.trendorin.Sotto.desktop` и иконку. Без этого порталы KDE и GNOME не выдают горячую клавишу. Чтобы удалить, сотрите сам файл, эти два файла и (при желании) `~/.config/sotto` и `~/.local/share/sotto`.

Собрать AppImage самому (root, docker и podman не нужны):

```sh
packaging/appimage/build.sh   # → dist/Sotto-<версия>-x86_64.AppImage
```

### Другие дистрибутивы

Поставьте Qt 6 (Widgets, Multimedia, DBus, Network), `layer-shell-qt`, `whisper.cpp`, `wl-clipboard` и `cmake`, затем:

```sh
./install.sh   # установит в ~/.local
```

## Как пользоваться

1. Запустите **Sotto** из меню. При первом запуске откроются настройки: скачайте модель (рекомендуется **Large v3 Turbo**, 547 МБ).
2. Клавиша по умолчанию **Meta+Space**. Поменять её можно кнопкой «Изменить…» в настройках.
   - **короткое нажатие:** запись идёт до следующего нажатия;
   - **удержание:** запись идёт, пока клавиша зажата.
3. Когда вы закончите, текст вставится в активное окно.

При первой вставке KDE спросит разрешение на «удалённое управление». Это портал, через который Sotto нажимает Ctrl+V. Отметьте «Запомнить», и вопрос больше не появится. Если разрешение не дать, текст останется в буфере обмена.

Индикатор можно перетащить мышью, и он запомнит место. Клик по нему останавливает запись, правый клик отменяет её.

### Команды

```sh
sotto --toggle    # начать / закончить (можно повесить на любую клавишу в настройках DE)
sotto --start | --stop | --cancel | --settings
```

## Откуда скачиваются модели

Все файлы берутся с Hugging Face (или с зеркала, переключается в настройках, «Источник»):

| Что | Откуда | Лицензия |
|---|---|---|
| Модели Whisper (ggml) | [huggingface.co/ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp) | MIT (модели OpenAI Whisper) |
| Silero VAD (0.9 МБ) | [huggingface.co/ggml-org/whisper-vad](https://huggingface.co/ggml-org/whisper-vad) | MIT |
| Зеркало | [hf-mirror.com](https://hf-mirror.com): та же структура, если Hugging Face недоступен | |

Прямая ссылка: `https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-<модель>.bin`. После загрузки размер файла сверяется с заявленным сервером, недокачанные файлы удаляются. Можно скачать модель вручную и положить в папку моделей: она появится в списке.

## Удаление

Любой из способов:

- **Настройки → «Удалить Sotto…»**: удаляет программу (для пакета pacman спросит пароль), ярлык, автозапуск, горячую клавишу и, если отметить, модели с настройками;
- `sotto --uninstall` делает то же самое;
- `./uninstall.sh` из папки с исходниками (`--purge` удалит и модели, `--keep` оставит).

После этого в системе ничего не остаётся.

## Если что-то не работает

Логи пишутся в системный журнал:

```sh
journalctl --user -t sotto -f
```

Там видно, с какого микрофона идёт запись, сколько секунд записано, используется ли видеокарта и сколько заняло распознавание.

- **Долго распознаёт.** Если в логе `gpu: false`, видеокарта не используется: установите `ggml-vulkan` или выберите модель **Small**.
- **Текст не вставляется.** Настройки → «Доступ к вводу» → «Разрешить…». В терминалах выберите Ctrl+Shift+V.
- **Клавиша не срабатывает.** Проверьте назначение в «Изменить…» (Параметры системы → Комбинации клавиш → Sotto) или повесьте любую клавишу на `sotto --toggle`.

## Где что лежит

| Что | Где |
|---|---|
| Настройки | `~/.config/sotto/sotto.conf` |
| Модели | `~/.local/share/sotto/models/` (можно положить свою `ggml-*.bin`) |
| Автозапуск | `~/.config/autostart/io.github.trendorin.Sotto.desktop` (только если включён) |

## Советы

- В терминалах вставка работает по **Ctrl+Shift+V**. Его можно выбрать в настройках.
- В поле «Словарь» впишите имена и термины, которые часто произносите. Whisper будет писать их правильно.
- Подробный вывод whisper/ggml: `SOTTO_DEBUG=1 sotto`.
